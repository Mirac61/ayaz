# Ayaz Brand Identity & Icons

*Ayaz* (Old Turkic *ayas*: clear, cloudless sky; Turkish *ayaz*: crisp, freezing winter cold on a clear night) embodies the philosophy of the editor: **crystalline clarity, razor-sharp speed, and zero distraction**.

## 1. Primary Identity: Kälte & Frost (Standard)

The primary brand mark is a 16-faceted geometric ice crystal. It conveys sub-zero sharpness, precision keyboard navigation, and high-performance editing.

- **Start Screen / UI Emblem:** [`ayaz-frost-start.svg`](./ayaz-frost-start.svg)
- **Application & Dock Icon:** [`ayaz-frost-dock.svg`](./ayaz-frost-dock.svg)

## 2. Secondary Identity: Tiefe Ruhe (Alternative)

The alternative brand mark captures the cosmic silence of a starry winter night: a luminous lunar corona around an obsidian void with four cardinal coordinate notches.

- **Start Screen / UI Emblem:** [`ayaz-ruhe-start.svg`](./ayaz-ruhe-start.svg)
- **Application & Dock Icon:** [`ayaz-ruhe-dock.svg`](./ayaz-ruhe-dock.svg)
